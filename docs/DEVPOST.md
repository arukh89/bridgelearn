## Description (paste into Devpost — 189 words, limit 300)

BridgeLearn is an AI study buddy for students everywhere — especially those
without fast internet, paid tutors, or a personal device. Paste any lesson
text and it instantly builds a mixed quiz (multiple choice, fill-in-the-blank,
true/false), flashcards, and a spaced-repetition review plan, all generated
entirely on your device. No account, no server, no API key, no data ever
leaves the browser — so it works on a shared phone, a school computer, or a
library's one slow connection. It also scores the lesson's reading level
(Flesch Reading Ease + grade level) so teachers can see if a text fits their
students. The quiz generator is deterministic: the same text always produces
the same quiz, so a teacher can reproduce or print it for a whole class. Why
it matters: talent exists everywhere, but quality study help doesn't.
BridgeLearn closes that gap by turning any textbook page into interactive
study material in one click — free, offline-first, and built for the students
the tech ecosystem usually forgets. Built with: vanilla HTML/CSS/JavaScript,
zero dependencies, zero network calls. AI disclosure: built with AI coding
assistance (Muse); all generation runs on-device with no external AI service.
