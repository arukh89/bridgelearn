    Why offline-first?

    Talent exists everywhere, but fast internet and paid tutors don’t. BridgeLearn runs as a single page with no server, no account and no API key, so it works on a shared phone, a school computer, or a village library’s one slow connection — the same lesson, the same quiz, for every student. All generation is deterministic and reproducible: the same text always produces the same quiz, so a teacher can print it or share it with a class.
